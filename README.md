 # Starbucks — Учебный проект ☕

Одностраничный сайт кофейни Starbucks, созданный для отработки навыков верстки.

---

## 🎯 О проекте

Это **учебный проект**, цель которого — попрактиковаться в создании сложных сеток и плавных CSS-анимаций. Дизайн вдохновлен официальным сайтом Starbucks.

⚠️ **Важно:** адаптивная верстка (под мобильные устройства) в рамках этого проекта **не реализовывалась**. Проект создавался для отработки конкретных навыков.

## 🛠 Технологии

*   **HTML5** — семантическая верстка.
*   **CSS3** — **CSS Grid** (для построения сложной сетки), **CSS-анимации** (плавные эффекты при наведении и появлении элементов), Flexbox (для выравнивания внутри блоков), CSS-переменные.
*   **БЭМ** — именование классов.
*   **Figma** — работа с макетом.

## ✨ Что реализовано

*   **Сложная сетка** на CSS Grid: блоки разной ширины и высоты, которые корректно выстраиваются в единую композицию.
*   **Плавные CSS-анимации**:
    *   Эффекты при наведении на кнопки и карточки (изменение цвета, масштабирование, сдвиг).
*   **Стилизация** в фирменных цветах Starbucks (зеленый, белый, черный).
